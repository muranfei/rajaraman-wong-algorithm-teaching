# 来源与限制

## 主要来源

- 课程课件：*04-clustering.pdf*
- 课件标题：*EST8717 Algorithms and Machine Learning in VLSI Physical Design*
- 相关章节：*Lecture 5 Clustering*
- 本视频主要依据：Rajaraman and Wong Algorithm 部分

## 内容范围

本项目对课件中的算法定义、延迟模型、三个执行阶段、公式和算例进行了中文重述与重新可视化。

本项目没有重新分发课件原文。教学网站与仓库中的文字、图解和视频用于课程学习和教学展示。

## 已知限制

1. 视频采用静态图解配合旁白，重点在算法逻辑和算例推演，不是对论文全部实验的复现。
2. 算例来自课件，用于解释算法步骤，不代表对所有电路规模或延迟模型都进行了实验验证。
3. 视频说明了算法的延迟最优性质，但没有展开完整的形式化证明。
4. 节点复制会增加面积和引脚开销；视频对该权衡进行了概念解释，没有进行实际面积估算。
5. 本项目不是官方课程材料，不应替代教师讲义、论文原文或正式作业要求。
