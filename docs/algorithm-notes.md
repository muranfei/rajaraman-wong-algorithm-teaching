# Rajaraman and Wong Algorithm 系统讲义

## 学习目标

完成本讲义后，应能够：

1. 解释延迟导向聚类与割边数导向聚类的区别。
2. 写出节点延迟、簇内延迟和簇间延迟组成的延迟模型。
3. 按初始化、标记和聚类三个阶段执行算法。
4. 说明 `l1`、`l2` 与 `l(v) = max(l1, l2)` 的含义。
5. 用一个例子解释节点复制为什么可能带来延迟最优结果。

## 1. 问题定位

聚类方法可以按优化目标分成两类：

- 以减小簇间连接数为目标，通常称为 cutsize 导向。
- 以减小主输入 PI 到主输出 PO 的最大路径延迟为目标，称为 delay 导向。

Rajaraman and Wong 算法属于后者。它是第一个在一般延迟模型下得到延迟最优解的延迟导向聚类算法。

算法输入为：

- 一个有向无环图 DAG。
- 每个簇允许包含的节点数上限。

算法目标为：

- 最小化从任一 PI 到任一 PO 的最大路径延迟。

算法允许节点复制。同一节点可以出现在多个簇中，这是获得延迟最优结果的重要机制，同时也会增加节点数、面积和引脚开销。

## 2. 延迟模型

本算法采用如下延迟模型：

| 延迟类型 | 含义 | 符号 |
| --- | --- | --- |
| 节点延迟 | 信号经过节点自身产生的延迟 | `d` |
| 簇内延迟 | 同一簇内部传播的额外延迟 | `0` |
| 簇间延迟 | 信号跨越一次簇边界产生的延迟 | `D` |

关键直觉是：把关键路径上的节点放进同一个簇，可以避免簇间延迟；如果路径被拆到不同簇中，每跨一次边界就要增加一次 `D`。

## 3. 三个阶段

### 3.1 初始化

计算全对最大延迟矩阵 `Δ(x, v)`：

- 它表示从节点 `x` 的输出到节点 `v` 的输出，只计节点延迟的最大延迟。
- 矩阵规模为 `n × n`，其中 `n` 是节点总数。
- 对角线和不可达位置取 `0`。

随后设置标签：

- PI 节点的初始标签等于该节点延迟。
- 所有非 PI 节点的初始标签为 `0`。

### 3.2 标记

按照拓扑序处理每个节点 `v`：

1. 取节点 `v` 和它的全部前驱，形成子图 `Gv`。
2. 对子图中每个 `x ≠ v`，计算：

```text
lv(x) = l(x) + Δ(x, v)
```

3. 按 `lv` 从大到小把节点放入集合 `S`，依次加入 `cluster(v)`，直到再加入会违反簇大小约束。
4. 计算：

```text
l1 = 簇内 PI 节点的最大 lv，若不存在 PI 则为 0
l2 = 剩余节点的最大 lv + D，若没有剩余节点则为 0
```

5. 更新节点标签：

```text
l(v) = max(l1, l2)
```

`l1` 表示不跨簇就能到达 PI 的路径；`l2` 表示还需要跨出当前簇的路径，因此要加入一次簇间延迟 `D`。

### 3.3 聚类

按照逆拓扑序生成实际簇：

1. 把所有 PO 节点放入集合 `L`。
2. 从 `L` 取出节点 `v`，按照标记阶段得到的 `cluster(v)` 成簇。
3. 计算该簇的输入节点集合 `input(v)`。
4. 把 `input(v)` 中尚未成簇的节点加入 `L`。
5. 重复处理，直到 `L` 为空。

## 4. 课件算例

算例参数：

- 节点延迟 `d = 1`
- 簇间延迟 `D = 3`
- 簇大小上限 `4`
- `PI = {a, b, c}`
- `PO = {k, l}`

非 PI 节点的一个拓扑序为：

```text
T = [d, e, f, g, h, i, j, k, l]
```

最终得到八个簇：

```text
k = {g, i, j, k}
l = {e, g, j, l}
d = {a, b, d}
e = {b, c, e}
f = {a, f}
h = {c, h}
b = {b}
c = {c}
```

节点 `g、e、j、b、c` 出现在多个簇中，说明发生节点复制。

## 5. 易错点

1. `Δ(x, v)` 只计节点延迟，不直接包含簇间延迟。
2. `l1` 与 `l2` 的来源不同，不能用同一个最大值替代。
3. `cluster(v)` 是标记阶段得到的候选簇，实际簇在逆拓扑序聚类阶段生成。
4. 节点复制不是异常，而是算法换取延迟最优的主动手段。
5. 延迟最优不等于面积、引脚或功耗同时最优。

## 6. 算法性质与后续工作

在节点延迟为 `d`、簇内延迟为 `0`、簇间延迟为 `D` 的模型下，Rajaraman and Wong 算法可以得到延迟最优解。

从计算代价看：

- 初始化需要计算全对最长路径。
- 标记阶段需要为每个节点处理它的前驱子图。
- 整体开销会随电路规模增长而明显增加。

相关后续工作包括：

- Yang 与 Wong 1994：用复制最小化割边数。
- Vaishnav 与 Pedram 1995：在延迟最优前提下最小化功耗。
- Yang 与 Wong 1997：加入面积与引脚约束。
- Pan 等 1998：处理带 retiming 的时序电路。
- Cong 与 Romesis 2001：给出两级启发式方法。
